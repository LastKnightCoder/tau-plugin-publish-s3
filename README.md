# S3 静态托管发布

把 Tau 里选中的文章、卡片和项目文档发布成一个网站，放进你自己的对象存储：AWS S3，或者 Cloudflare R2、MinIO 这类兼容 S3 的服务。之后改了内容，再点一次「发布」就会更新，只上传有变化的文件。

## 三步开始

1. **装好插件**：在插件中心安装「S3 静态托管发布」，再装一个博客模板（比如「Tau 博客」），它决定网站长什么样。
2. **填写发布位置**：在侧边栏打开「发布」，点「去设置」打开站点设置，「服务」选「S3 静态托管发布」，填写账号和存储桶。
3. **勾选内容并发布**：在左侧勾选要公开的内容，点「发布」。

## 需要填写什么

- **Access Key 和 Secret Key**：服务商给你的访问密钥。
- **Bucket 和 Region**：存储桶的名字和所在地区，在服务商控制台里都能看到。
- **Endpoint**：用 AWS 以外的服务（R2、MinIO 等）时填写，服务商的文档里会给出这个地址。

其他选项一般不用改：

- **访问路径**：网站放在子路径下时填写，比如 `/blog`；
- **对象前缀**：网站文件放进存储桶里的哪个文件夹；
- **URL 风格**：默认「路径风格」；服务商要求用 `存储桶名.域名` 这种地址时，改为「虚拟主机风格」。

## 常见问题

**测试连接通过了，发布时还有文件失败？** 测试连接只能确认账号能连上。请检查这个账号是否有上传和删除文件的权限，处理后重新发布，已成功的文件会被跳过。

**网站打开要怎么设置？** 存储桶的静态网站托管、公开访问和自定义域名在服务商那边设置，再把网站地址填进站点设置的「公开 URL」。

只想把网站导出到本地文件夹、自己部署的话，不需要安装这个插件，在站点设置里选「本地导出」。完整说明见 [发布](https://taunote.app/docs/publish/)。
