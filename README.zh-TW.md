# S3 靜態託管發佈

把 Tau 裡選中的文章、卡片和專案文件發佈成一個網站，放進你自己的物件儲存：AWS S3，或是 Cloudflare R2、MinIO 這類相容 S3 的服務。之後改了內容，再點擊一次「發佈」就會更新，只上傳有變動的檔案。

## 三步開始

1. **裝好外掛**：在外掛中心安裝「S3 靜態託管發佈」，再裝一個部落格範本（例如「Tau 部落格」），它決定網站的外觀。
2. **填寫發佈位置**：在側邊欄開啟「發佈」，點擊「前往設定」開啟站點設定，「服務」選擇「S3 靜態託管發佈」，填寫帳號和儲存桶。
3. **勾選內容並發佈**：在左側勾選要公開的內容，點擊「發佈」。

## 需要填寫什麼

- **Access Key 和 Secret Key**：服務商提供給你的存取金鑰。
- **Bucket 和 Region**：儲存桶的名稱和所在地區，在服務商控制台裡都能看到。
- **Endpoint**：使用 AWS 以外的服務（R2、MinIO 等）時填寫，服務商的文件裡會提供這個網址。

其他選項一般不用改：

- **存取路徑**：網站放在子路徑下時填寫，例如 `/blog`；
- **物件前綴**：網站檔案放進儲存桶裡的哪個資料夾；
- **URL 風格**：預設「路徑風格」；服務商要求用 `儲存桶名稱.網域` 這種網址時，改為「虛擬主機風格」。

## 常見問題

**測試連線通過了，發佈時還有檔案失敗？** 測試連線只能確認帳號能連上。請檢查這個帳號是否有上傳和刪除檔案的權限，處理後重新發佈，已成功的檔案會被略過。

**網站開啟要怎麼設定？** 儲存桶的靜態網站託管、公開存取和自訂網域在服務商那邊設定，再把網站網址填進站點設定的「公開 URL」。

只想把網站匯出到本機資料夾、自行部署的話，不需要安裝這個外掛，在站點設定裡選「本機匯出」。完整說明見 [發佈](https://taunote.app/docs/publish/)。
